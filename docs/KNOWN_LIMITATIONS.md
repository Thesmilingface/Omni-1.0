# Known limitations

This version is an unverified initial scaffold. The environment used to write it did not provide a local shell/build runner, so no dependency installation, test execution, GUI launch, visual inspection, Windows hardware test, or archive extraction was performed.

Not yet implemented: streaming/cancellation, conversation list/search/titles, OS keychain, voice input, Fish Audio synthesis/playback, audio envelopes, Live2D model loading, transparent desktop overlay, web search/research, fully permissioned agent planner, Java, Windows installer, clean-install package, ZIP artifact, complete settings UI, retention controls, database migrations, or broad integration/GUI tests. Do not describe these as working.

Live2D runtime/model licensing and availability must be checked for the specific intended distribution. This repository does not bundle assets from a third party.
