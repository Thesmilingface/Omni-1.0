# Companion animation

The Rust UI draws a procedural 2D face that changes between idle and thinking while a request is active. It is not a rigged model and has no mouth/audio synchronization. No model or SDK is redistributed. A future adapter can load a user-provided layered sprite or a properly licensed Live2D model/runtime after verifying SDK terms, model permissions, and redistribution rights. Reduced-motion/transparent overlay controls are not yet implemented.
