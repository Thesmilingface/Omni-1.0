# AI providers

Implemented adapters: Groq Chat Completions, OpenAI Chat Completions (including configurable base URL), and Gemini `generateContent`. Provider APIs and model availability can change; confirm current model identifiers in the provider console. The service reports missing/invalid configuration instead of inventing a response. Streaming, cancellation, usage accounting, automatic retries, and secure OS keychain storage are not implemented yet.

The supplied ChatGPT key was redacted and is unusable. Keys disclosed in the conversation should be revoked and replaced before use.
